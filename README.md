# 컴활 1급 필기 개념게임

컴퓨터활용능력 **1급 필기**를 게임으로 익히는 학습 도구입니다.
설치 없이 브라우저에서 바로 실행되는 단일 웹앱(정적 사이트)입니다.

## 게임 모드
- 🃏 **개념 카드** — 용어/설명을 넘기며 부담 없이 학습
- ⚡ **스피드 퀴즈** — 4지선다 + 타이머 + 콤보 점수
- ⭕ **OX 퀴즈** — 헷갈리는 개념 빠른 판단
- 🔗 **용어 매칭** — 용어↔설명 짝맞추기 기억력 게임

진행 상황(별·XP·최고 정답률)은 브라우저 localStorage에 저장됩니다.

## 과목
- ✅ 제1과목 **컴퓨터 일반** (6단원)
- ⏳ 제2과목 스프레드시트 일반 (준비 중)
- ⏳ 제3과목 데이터베이스 일반 (준비 중)

## 콘텐츠 추가/수정
문제와 개념은 `data/` 폴더의 자바스크립트 파일에 들어 있습니다.
- `data/comp.js` — 컴퓨터 일반
- `data/excel.js` — 스프레드시트 일반
- `data/access.js` — 데이터베이스 일반

각 단원 구조:
```js
{
  id, name, icon,
  cards: [{ t:"용어", d:"설명" }],          // 개념카드 + 매칭
  quiz:  [{ q:"문제", o:[보기4], a:정답index, ex:"해설" }], // 스피드 퀴즈
  ox:    [{ s:"서술문", a:true/false, ex:"해설" }],  // OX 퀴즈
}
```
`ready:true`로 바꾸면 해당 과목이 활성화됩니다.

## 실행
`index.html`을 열면 됩니다. (GitHub Pages 배포 시 저장소 루트에 그대로 올리면 동작)
